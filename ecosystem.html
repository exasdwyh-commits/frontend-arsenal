06

另一份清单：0 成本动效工作室

Studio

上面 18 个是「做前端动效」的库，这 14 个拼的是整间工作室：动、物理、图表、2D 动画、3D 生成、视频生成、配乐。授权都写清了，能不能在浏览器里跑也标了——不把「要 GPU」的东西说成能直接抄。

anime.js 动画引擎MIT浏览器

缓动、时间轴、SVG 变形的祖师爷，半条街的顺滑都出自它。库内等价：stagger-in / ease-shelf / timeline-orch

react-spring 弹簧物理MIT浏览器

把「每次 UI 移动都要有质量」变成默认值。库内等价：spring-enter / rs-spring-presets / elastic-drag

PixiJS 2D WebGLMIT浏览器

万级精灵同屏还稳 60fps，粒子与后期的快车道。库内等价：gl-particles-cloud / instanced-dots

p5.js 生成艺术LGPL-2.1浏览器

几行就出画面，创意编程的通用语。库内等价：p5-noise-drift / p5-dpr-sharp / watercolor-wash

matter-js 2D 刚体MIT浏览器

掉落、碰撞、堆叠，手感最像真实世界的那一档。库内等价：matter-spring-chain / matter-compound-body / gravity-drop

D3 数据可视化ISC浏览器

新闻编辑室那套图表背后基本都是它，力导向布局尤其好用。库内等价：force-graph（新）/ bar-grow / sparkline

OpenToonz 2D 动画软件BSD-3桌面端

吉卜力在用的制作工具，逐帧检查那套「洋葱皮」值得抄进 UI。思路等价：onion-skin（新）/ reduced-motion-tiers

Hunyuan3D-2 图生 3D腾讯社区许可需 GPU

一张图出带纹理网格，产线用得上；浏览器里只能拿到 glb 去显示。前端等价：photo-to-3d（新，假厚度）

TRELLIS 图生 3DMIT需 GPU

微软那套结构化 3D 生成，输出可直接进引擎。前端等价：photo-to-3d / gl-rotating-box

LTX-2 音视频生成开放权重许可需 GPU

一个模型出声又出画，最高 4K；采样过程本身就是动效素材。过程等价：diffusion-denoise（新）

LivePortrait 人像驱动自定义许可需 GPU

让一张照片说话、眨眼、点头，商用前务必看清条款。前端最接近的是视差，不是它能替代的：parallax-depth

RIFE 补帧MIT需 GPU

两个关键帧之间插出中间帧，慢动作靠它变顺。UI 里的同构做法是阻尼跟随：p5-lerp-ease / scroll-scrub

MusicGen 文生音乐代码 MIT / 权重 CC-BY-NC需 GPU

「描述氛围，出配乐」；权重是非商用授权，上线要换。浏览器里的同类：beat-grid（新，WebAudio 音序器）

Tone.js 音频框架MIT浏览器

合成器、节拍、效果器都有现成的；音序器别用定时器直接排音。库内等价：beat-grid（新）/ tone-click / spectrum-bars

一句话分工：anime / react-spring / PixiJS / p5 / matter / D3 / Tone.js 这 7 个在浏览器里真能跑，抄的是机制； OpenToonz 是桌面软件，抄的是工作流； Hunyuan3D-2 / TRELLIS / LTX-2 / LivePortrait / RIFE / MusicGen 这 6 个要 GPU，前端只负责喂输入、放输出——把它们写成「能在浏览器跑」是耍流氓。

合集：18 份可以直接丢给 AI 学的资料

Collection

这份清单是混着给的——视频渲染、3D 引擎、游戏状态机、粒子库都在里面。既然要做合集就照同一把尺子标：授权、能不能在浏览器里跑、我们库里哪条机制是它的原生版。上文已出现过 6 个，标了「上文已列」，不重复注水。

Remotion Skills 视频Remotion 许可

官方把「用 React 写视频」的规矩做成技能包给 AI 读，但 Remotion 本身是商用分级收费，个人免费。库内：无——图鉴不做视频渲染，交付那节只留了 gifenc

Motion Canvas 图解动画MIT

代码即分镜，画「解释型动画」最顺手。库内等价：timeline-orch / draw-path

Motion 动效内核MIT · 上文已列

布局动画与出现动画的默认答案（原 Framer Motion）。库内等价：spring-enter / stagger-in

Ola 数值平滑MIT

“让数字自己滑过去”的最小实现，不到 1KB。库内等价：count-up / scrub-number

Anime.js 时间线MIT · 上文已列

时间线 + 错峰 + SVG 变形的老牌答案。库内等价：ease-shelf / stagger-in

Manim 公式动画MIT

3Blue1Brown 那套数学动画，Python + LaTeX 出片。库内：draw-path（描边自绘同构，公式排版没有等价）

Shifty 缓动引擎MIT

只管补间与缓动曲线，小到能塞进任何项目。库内等价：ease-shelf / p5-lerp-ease

Two.js 2D 矢量MIT

同一份场景描述同时喂 SVG 和 Canvas 两套后端。库内等价：path-arc-length / draw-path

Lottie Web 矢量播放器MIT · 上文已列

把 AE 导出的 JSON 播出来，体积小、跨端一致。库内：无——图鉴只收手写机制，不收 AE 管线产物

TweenJS 顺序补间MIT

“等上一个结束再动下一个”的链式补间，CreateJS 家族。库内等价：timeline-tracks / timeline-orch

LUME HTML 写 3DMIT

用标签写 3D 场景，Web Components 路子。库内等价：css3d-card-ring / three-cube

gifenc GIF 导出MIT · 上文已列

Konva Canvas 画布MIT · 上文已列

Blender 绑定/角色GPL-2.0+

资产与绑定的源头，出的 glb 才是前端要接的东西。库内：无等价（前端只负责显示）

Three.js 3D 场景MIT · 上文已列

WebGL 的通用底座，几乎所有 3D 网页下面都有它。库内等价：gl-rotating-box / gl-instanced-grid

Godot 游戏状态机MIT

AnimationTree 那套状态机值得抄进复杂 UI 的动效编排。库内等价：timeline-orch（状态切换思路）

08

上游研读：6 个项目，抄机制不抄工程

Research

最近逐份读完的上游。照同一把尺子记：抄什么 / 不抄什么 / 授权 / 能不能在浏览器里跑。结论都落回了图鉴，项目本体一个都没装；这份记录留着，免得「研究过」下次又从零开始。

rea-video 视频分层Apache-2.0 · Python + ffmpeg，浏览器跑不了

抄：VIDEO.md 把一支片拆成「镜头 / 层 / 时长」的可读清单，AI 能照着改、人也能审。不抄：Python 渲染管线与 TTS、ffmpeg 依赖。库内：timeline-orch（分镜编排思路）

lemo-opuscar 风格库代码 MIT · 文档 CC BY-NC 4.0 · 成片 CC BY 4.0

抄：99 种风格各自带 STYLE.md，把构图、光、材质、镜头写成可执行约束，而不是一句「赛博朋克」。不抄：生成管线；非商用文档不能搬进商业模板。库内：无直接等价（图鉴不做生成）

effectcraft 合成器MIT OR Apache-2.0 · Rust 桌面 + 浏览器版，alpha

抄：308 个效果按「层 + 参数 + 关键帧」组织，参数即时间函数。不抄：Rust/wgpu 合成器本体、alpha 期 API。库内：time-scrub（render(t) 同构）

pixelfx 像素特效MIT · 纯 Canvas，能在浏览器跑

抄：颜色层 + 光层双缓冲、命中顿帧、解析式残影、12fps 姿态定格、调色板阶梯。不抄：整包像素后期。库内已落地 3 条：light-buffer / hitstop / echo-trail

awesome-opus5-5-videos 提示词集MIT · 纯文本清单

抄：703 条 prompt 按 Canvas / SVG / GSAP / GLSL / Three / Web Audio 标注技术栈，等于给「效果」加了第二维度。不抄：清单本体（不复制 703 条）。库内：待做——从 lib 字段派生技术栈筛选

ai-design-skills 设计规范MIT · 纯 Markdown，规则能直接落到 CSS

抄：两层颜色 token（Core 10 阶 → 语义别名，Light/Dark 用 mode 不写两套色）、命名文字样式（Heading/Title/Body/Button/Caption 全落尺度）、按钮 5 类型 × 5 状态、统一曲线 cubic-bezier(.22,1,.36,1)（布局 500ms / 颜色 300ms）、真实事实校验与 390px 验收。不抄：禁背景渐变 / 禁单边边框 / 默认不用 eyebrow——这是品牌落地页的规矩，图鉴是工具型界面，整套套上会把现有视觉语言废掉；Figma MCP 工作流也不适用于本站。库内：两套技能已全收（landing-page-design / figma-designer），动效无直接等价

为什么我们一个都不装

这些库都很强，但每一个都是一份要维护的依赖、一段要打包的体积、一个要跟版本走的 API。这个库的取舍反过来：只收机制，不收库——把「缓动曲线」「时间轴编排」「粒子发射」「FLIP 布局过渡」这些可复用的内核，用原生 JS/CSS 重写成自包含的 init(el) 模块，挂上就能跑，摘掉就干净。

所以上面每一行的「库内等价」不是替代关系，而是同一个机制的两种交付形态：要完整工程能力就用上游，要抄一个能跑的机制就回图鉴。首页那段实时短片、墨渗开屏、数字滚轮，全是这么来的。
