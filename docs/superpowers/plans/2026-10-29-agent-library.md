# Agent 参考库基础改造

目标：让 Agent 从业务需求检索资源、读取真实源码，并交付可追溯的实施方案。人类页面继续作为浏览和审核入口。

本阶段实现机器可读资源目录、命令行查询和使用协议。目录从现有清单生成，包含资源类型、场景依据、源文件、预览地址、使用边界和文件指纹。未知能力保持未知；既有效果归类为演示实现，技能为方法文档，视频为远程参考，不提升为已验证模板。

- [x] 编写目录生成器与查询命令，支持列表、详情、更新及新鲜度检查。
- [x] 生成索引并检查全部本地路径、唯一 ID、源文件指纹与场景依据。
- [x] 编写需求澄清、选型、组合及验收协议，以及结构化需求单示例。
- [x] 在仓库入口和 README 中提供 Agent 最短使用路径。
- [x] 验证查询、缺失 ID、筛选、索引过期检测。

范围：这一阶段提供供现有编程 Agent 调用的文件协议和 CLI。页面模板组合运行时与模型接入另行实现；当前不声称具有自动生成或组合验证能力。
