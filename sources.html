01 / CHARACTER ANIMATION

ClaudeAnimationBase

p5.js + p5.brush · MIT · 手绘卡通角色动画起步套件

它解决什么

  • 给 AI 助手一套"怎么画手绘卡通"的完整规则：角色 Clawd（31 种表情、5 个视角、道具与舞蹈）+ 引擎 + 无头渲染器，一句话就能开工。
  • 核心产出是 ANIMATION_GUIDE.md——不是 API 文档，而是一份"生成动画为什么丑"的解法集。

核心方法（三目标 · 七规则）

  • 三目标：Handmade（笔触+线条沸腾，逐帧手绘感）、Alive（永远有东西在动，脸是"演"出来的不是瞬切）、One piece（先有整片构思，再写任何代码）。
  • 规则 1-2 媒介与文字：全部走 p5.brush 平涂+墨线，禁用原生形状（"看起来像 2000 年代 Flash"）；线条每秒抖 12 次（boil）就是风格本身；绝不写字——用画面表达，"举着'我迷路了'的牌子"是经典失败案例。
  • 规则 3-4 每场有事件 + Timing：每个镜头首尾之间必须有变化；把观众要理解的内容列成 read，一次只给一个 read，快动作、慢含义——动作可以快，含义要留够停留时间。这是模型最常犯错的一条。
  • 规则 5-7：一切随 BPM 节拍动、表情用预备-眯眼-惊吓-回弹；每个接缝都要转场（笔刷擦除等），不硬开不硬停。
  • 工作流：分镜 contact sheet → 逐镜头搭建 → 三种自查（contact sheet 看全片形状 / strip 看单动作每一帧 / crop 看全分辨率细节）→ 无头 Chrome 逐帧渲染合成 MP4。
  • 引擎思想：帧是时间的纯函数（renderAt(t)），任何时刻可确定性重绘——这是所有"代码做片"项目的共同地基。

上手

  1. 克隆仓库，用 Claude Code（或任意 coding agent）打开。
  2. 先读 ANIMATION_GUIDE.md，再下需求："读 ANIMATION_GUIDE.md，做一段 15 秒 Clawd 抓蝴蝶的视频"。
  3. 本机需 Node + Chrome + ffmpeg；无独显时让模型避开水彩填充（每帧数秒）。
  4. 渲染：node render.mjs --clip --out=out/video.mp4；Chrome 打开 studio.html 可逐帧刮擦预览。

02 / MOTION GRAPHIC STYLES

mg-styles-15

Canvas · WebGL · Three.js · MIT · 15 种 MG 风格全开源

它解决什么

  • 15 支 10 秒成片，每支 = 风格说明 + 完整提示词 + 全部源码。画面和声音都是代码：SVG/Canvas/WebGL 画图，audio.py 合成配乐（103 个实录采样），无任何图像/视频生成模型。
  • 更值钱的是它的生产管线与评审方法——终评 7.57–8.21/10 是怎么磨出来的。

核心方法

  • 管线：一个风格提示词 → 网页实现 renderAt(t) → 无头 Chrome 逐帧截图 → ffmpeg 合成精确 10.000s + 同步音轨 → 另一个 AI 按 rubric.md 评审两轮。
  • 评审 rubric 七维度：风格忠实 / 概念惊艳 / 动效工艺（缓动、预备、跟随、弧线）/ 设计排版 / 完成质感 / 声音同步 / 技术规格。5 分=合格学生作业、8 分=高端代理商、9 分=入围——首渲染大多只值 5-7 分，不许放水。
  • 修复清单格式：按时码列出 5-10 条，每条写清"错在哪（可观测）+ 为什么重要 + 具体怎么改（曲线、帧数、px、色值）"，至少一条必须提升 wow 值而非只抛光。
  • 改自己的内容：只换 Creative seed（故事/品牌/文案/配色）和 Output（可改竖屏 1080×1920）；Signature features 段一个字不动——那是风格被一眼认出的依据。

上手

  1. 空文件夹打开能写码、能跑命令的 AI 助手（如 Claude Code）；本机需 Node 22.12+、Chrome、ffmpeg、Python 3.11+。
  2. 把 prompts/*.md 整段提示词发给它，等成片。
  3. 要提升：另开一个 AI 会话贴 rubric.md 评审提示词，把评审意见贴回制作会话再改一轮（原片就是这么迭代的）。
  4. 偷懒路径：直接让它用仓库的 harness/render.mjs 渲染、lib/audio 出配乐。

03 / PRODUCT VIDEO

video-shotcraft

Remotion · Apache-2.0 · 电影感产品宣传片制作技能

它解决什么

  • 从前端项目/网页直接产出电影感产品宣传片：124 张镜头配方卡（本站已收录）、Ink Press 36.2s 验收模板、可复用 Remotion 组件、Freesound 音效选材工具、八阶段流水线。
  • 镜头卡是通用动效词汇——可整片用，也可单独抽一张卡做任意视频里的一个镜头。

核心方法

  • 三种互不合并的模式：① 模板复刻（读 TEMPLATE.md 换素材）② 自主自由创作（读 pipeline.md，Agent 全程自主）③ 共同创作（产品简报→视觉方向→镜头映射→分镜逐段确认）。开工前先做一次只读产品检查再推荐模式。
  • 八阶段流水线：产品理解 → styleframe 视觉方向 → 功能到镜头映射 → 分镜与素材清单 → 最终素材采集 → Remotion 镜头实现（30fps / 1920×1080）→ 声音（BGM 全片骨架 + SFX 钉在效果关键帧）→ 终检（逐帧/胶片全片回看）。
  • 硬规则：复刻页面必须真实截图（dev server + 无头 2x 全页 + 元素抠图 + layout.json 坐标），不许手搓 UI；视觉语言必须从产品自身设计系统提取 tokens 生长（字体/栅格/配色），不另造"宣传片皮肤"；每个镜头只有一个动效关键信息；确定性渲染（禁 Date.now()/Math.random()）。
  • 声音先行：librosa 测 BGM 拍点定 BPM，转场/字卡/命中全部对拍；一镜一重点，重复即删。

上手

  1. 装成 agent skill，或 clone 仓库后在项目里对 Claude Code / Codex 说需求。
  2. 提供项目路径/网址/录屏 → 它做只读产品检查 → 给你三种模式的推荐 → 你选定后开工。
  3. 只要单个镜头：从镜头卡挑名字（如 spotlight-hero-card）直接点名，它读卡+demo 源码适配。
  4. 浏览动态样片并挑镜头：官方 Gallery（本页"镜头与叙事"区已收录全部 124 卡的中文数据）。

04 / CINEMA IN CODE

lemo-opuscar

Canvas · WebGL · three.js · MIT 代码 + CC BY 4.0 样片 · 66 种电影风格

它解决什么

  • 66 种"代码做片"电影风格，每种 = STYLE.md 提示词 + 一支代码成片；配套两份方法论文档：DIRECTOR.md（怎么导）和 TECHNIQUE.md（怎么建）。
  • 它回答的是"给 AI 一个风格后，如何像小工作室一样把片子做完"。

DIRECTOR.md 十三条导演法（精华）

  • 先找标杆再动笔：写任何东西前，先定 1-2 部把标准拉满的参考作（片子/片头/广告）。
  • 故事：一个主体、一个目标、一次转折；先写 TREATMENT.md 再画任何帧。
  • 验证 look：角色先出模型表（转面+表情+关键姿势+色板）+ 两张风格帧。
  • 声音是半部片：每个可见动作都有声（落地、翻页、剪切）；音乐网格先定——先写 cue map 再动画，脚本检查每个 cue 对拍。
  • 运镜：每个镜头要有理由，全片至少 4 种运镜 + 真实的景别变化；2D 也有推拉/视差/焦移。
  • 表演：有意义的动作必须有预备-动作-跟随；常见失败：主体太小、太远、贴画面边缘。
  • 交片前：评审循环——contact sheet、关键动作 0.2s 条带、带声全速看一遍；版权红线：参考只学语法，不抄角色/设计/旋律/logo。

TECHNIQUE.md 十二条制作法（精华）

  • 画面是时间的函数；单一 timeline 驱动一切——配乐、混音、字幕、检查全从同一份时间线导出。
  • TTS 只是默认（有录音用录音）；配乐按 cue map 原创（禁通用钢琴弦乐）；sfx.py 程序化合成 foley。
  • 字幕 cues.json → srt.py → .srt 并把样式烧进页面；three.js r170 无头 WebGL2、2× 超采降采样。
  • 素材只用 CC0 / CC BY / OFL，逐条记入 CREDITS；评审循环：每 1-2s 一张 contact sheet，至少两轮全片。

上手

  1. 装 skill：claude plugin marketplace add lemomo-ai/lemo-opuscar + claude plugin install；或直接 clone。
  2. 直接说需求，点名中英文风格："用 watercolor 风格做 45 秒，讲我家的咖啡农场，女声旁白"。
  3. 没想好就输 /lemo-opuscar:lemo-opuscar，它会问：题材待定项、有没有自己的素材、要不要先看分镜。
  4. 它一次读三份指南开工：DIRECTOR.md（导）→ TECHNIQUE.md（建）→ styles/<风格>/STYLE.md（长什么样）。
